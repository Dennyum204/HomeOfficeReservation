# HO-020 — Comparações visuais

As imagens “depois” foram capturadas na aplicação real com API/PostgreSQL isolados e contas sintéticas, em Chromium desktop (1280×720), viewport Pixel 5 e emulador Android HO020_Visual (1080×2340). Não são mockups.

O “antes” usa a evidência real preservada de HO-016 integrada em main, incluindo a revisão do cabeçalho Android. Datas, scroll e dados não são idênticos entre campanhas; esta comparação documenta apresentação, não diferenças de dados. As cinco imagens fornecidas pelo utilizador orientaram a correção e não foram republicadas porque contêm identificação pessoal.
